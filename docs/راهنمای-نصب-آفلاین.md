# راهنمای ساخت خروجی و نصب روی سیستم‌های آفلاین

این راهنما توضیح می‌دهد چطور از پروژه یک فایل نصب بسازید و آن را روی سیستم‌هایی نصب کنید
که **نه Visual Studio دارند، نه .NET، و نه اینترنت**.

منطق کلی: شما **یک بار** روی «سیستم توسعه» (سیستم خودتان که اینترنت دارد) خروجی می‌سازید،
سپس آن خروجی را روی هر تعداد «سیستم مقصد» (سیستم‌های آفلاین شرکت) نصب می‌کنید.

---

## بخش ۱ — یک‌بار روی سیستم توسعه (نیازمند اینترنت)

این کارها را فقط یک بار و روی سیستمی که اینترنت دارد انجام می‌دهید.

### گام ۱: نصب پیش‌نیازها

۱. **.NET 8 SDK**  → از `https://dotnet.microsoft.com/download/dotnet/8.0`
   بخش «SDK x64» را دانلود و نصب کنید. (نه Runtime، حتماً SDK.)

۲. **Inno Setup 6** (برای ساخت فایل نصب، رایگان)  → از `https://jrsoftware.org/isdl.php`
   فایل `innosetup-6.x.x.exe` را دانلود و نصب کنید.

بررسی نصب .NET: یک PowerShell باز کنید و بزنید:
```powershell
dotnet --version
```
باید چیزی مثل `8.0.xxx` نمایش دهد.

### گام ۲: ساخت نسخهٔ خوداتکا (Self-contained)

«خوداتکا» یعنی .NET داخل خود برنامه بسته‌بندی می‌شود، پس سیستم مقصد نیازی به نصب .NET ندارد.

در PowerShell، به پوشهٔ ریشهٔ پروژه بروید (جایی که فایل `CertificateAutomation.sln` هست):
```powershell
cd مسیر\پروژه\CertificateAutomation

dotnet restore

dotnet publish src\CertificateAutomation.UI\CertificateAutomation.UI.csproj `
    -c Release `
    -r win-x64 `
    --self-contained true `
    -p:PublishSingleFile=true `
    -p:IncludeNativeLibrariesForSelfExtract=true `
    -o publish
```

توضیح پارامترها:
- `-r win-x64` : برای ویندوز ۶۴ بیتی. اگر سیستم مقصد ۳۲ بیتی است، `win-x86` بگذارید.
- `--self-contained true` : .NET را داخل خروجی می‌گنجاند.
- `-p:PublishSingleFile=true` : همه‌چیز در یک فایل exe جمع می‌شود.

بعد از اتمام، پوشهٔ `publish` ساخته می‌شود و داخلش `CertificateAutomation.exe` هست.
حجم خروجی حدود ۱۵۰ مگابایت است (چون کل .NET درونش است) — این طبیعی است.

> **نکتهٔ مهم:** فرمان `publish` باید روی **ویندوز** اجرا شود، چون برنامه WPF است و فقط
> روی ویندوز build می‌شود. روی لینوکس/مک کار نمی‌کند.

### گام ۳ (اختیاری ولی توصیه‌شده): تست خروجی

قبل از ساخت فایل نصب، خروجی را همان‌جا تست کنید:
```powershell
.\publish\CertificateAutomation.exe
```
اگر برنامه بالا آمد و کار کرد، ادامه دهید.

### گام ۴: ساخت فایل نصب (Setup.exe)

۱. فایل `installer\setup.iss` را با Inno Setup باز کنید (راست‌کلیک → Open with Inno Setup،
   یا از داخل خود Inno Setup: File → Open).
۲. از منو: **Build → Compile** (یا کلید F9).
۳. پس از اتمام، فایل نصب در پوشهٔ `dist` ساخته می‌شود:
   `dist\CertificateAutomation-Setup-1.0.0.exe`

همین یک فایل، تمام چیزی است که برای نصب روی سیستم‌های مقصد لازم دارید.

## بخش ۲ — روی هر سیستم مقصد (بدون اینترنت، بدون Visual Studio)

فقط فایل `CertificateAutomation-Setup-1.0.0.exe` را با فلش یا شبکهٔ داخلی به سیستم مقصد
ببرید و اجرا کنید:

۱. روی `CertificateAutomation-Setup-1.0.0.exe` دوبار کلیک کنید.
۲. چند بار «بعدی» را بزنید.
۳. نصب کامل می‌شود و میان‌بر روی میز کار و منوی Start ساخته می‌شود.
۴. برنامه را اجرا کنید.

در اولین اجرا، برنامه خودش پایگاه داده، پوشه‌ها، کاربر مدیر و تنظیمات پیش‌فرض را می‌سازد.
**هیچ تنظیم دستی، برنامه‌نویسی یا ساخت پایگاه داده‌ای لازم نیست.**

قالب‌های نمونه و فایل Excel نمونه هم به‌طور خودکار در این مسیرها کپی می‌شوند:
- قالب‌ها: `C:\ProgramData\CertificateAutomation\Templates`
- داده‌های نمونه: `C:\ProgramData\CertificateAutomation\SampleData`

### اولین گواهی در ۵ کلیک

۱. برنامه را باز کنید.
۲. بخش «کارکنان» → «بارگذاری از Excel» → فایل
   `C:\ProgramData\CertificateAutomation\SampleData\Employees.xlsx` را انتخاب کنید.
۳. بخش «قالب‌ها» → «همگام‌سازی قالب‌ها».
۴. بخش «صدور نامه» → یک شخص → یک قالب → «صدور».
۵. تمام! نامه ساخته، شماره‌گذاری، ثبت و باز می‌شود.

## بخش ۳ — خروجی PDF و چاپ روی سیستم‌های ایران (مهم)

برنامه برای «پر کردن قالب» به هیچ نرم‌افزار جانبی نیاز ندارد؛ سند Word را خودش می‌سازد.
اما برای «خروجی PDF» و «چاپ باکیفیت»، به یکی از این دو نیاز دارد:

**گزینهٔ الف — Microsoft Word:** اگر روی سیستم مقصد Word نصب و **فعال‌سازی‌شده** باشد،
برنامه خودکار از آن استفاده می‌کند (بهترین کیفیت).

**گزینهٔ ب — LibreOffice (رایگان، توصیه‌شده برای سیستم‌های بدون Word فعال):**
چون روی خیلی از سیستم‌های ایران Word فعال‌سازی‌شده نیست، LibreOffice گزینهٔ مطمئن است.

نصب آفلاین LibreOffice:
۱. روی سیستم توسعه (با اینترنت)، نصاب آفلاین LibreOffice را دانلود کنید:
   `https://www.libreoffice.org/download/download/` (نسخهٔ Windows x86_64، فایل حدود ۳۰۰MB).
۲. این فایل نصب را هم با فلش به سیستم مقصد ببرید و نصب کنید.
۳. تمام — برنامه خودکار LibreOffice را تشخیص می‌دهد و برای PDF و چاپ از آن استفاده می‌کند.

**اگر هیچ‌کدام نصب نبود:** برنامه باز هم کار می‌کند و سند Word را می‌سازد؛ فقط دکمهٔ PDF
پیام می‌دهد که برای PDF باید Word یا LibreOffice نصب شود. چاپ هم از طریق قابلیت پیش‌فرض
خود ویندوز انجام می‌شود.

> برنامه خودش تشخیص می‌دهد چه چیزی روی سیستم هست و بهترین گزینه را انتخاب می‌کند.
> شما فقط کافی است (در صورت نیاز به PDF) LibreOffice را نصب کنید.

## بخش ۴ — پرسش‌های رایج

**آیا سیستم مقصد به اینترنت نیاز دارد؟**
خیر. نه برای نصب، نه برای اجرا. برنامه کاملاً آفلاین است و هیچ داده‌ای به اینترنت نمی‌فرستد.

**آیا سیستم مقصد به .NET نیاز دارد؟**
خیر. چون خروجی خوداتکاست، .NET داخلش هست.

**آیا سیستم مقصد به Visual Studio نیاز دارد؟**
خیر. Visual Studio فقط روی سیستم توسعهٔ شما (برای ساخت یک‌بارهٔ خروجی) لازم است — و حتی
آن هم لازم نیست؛ فقط .NET SDK کافی است و فرمان `dotnet publish` را از PowerShell می‌زنید.

**فایل Excel و قالب‌های واقعی شرکت را کجا بگذارم؟**
پس از نصب، از داخل برنامه در بخش «تنظیمات» (فاز ۷) می‌توانید مسیر فایل Excel و پوشهٔ
قالب‌ها را به مسیر دلخواه تغییر دهید. یا مستقیماً فایل‌های خود را در
`C:\ProgramData\CertificateAutomation\Templates` کپی کنید و «همگام‌سازی» را بزنید.

**داده‌ها کجا ذخیره می‌شوند و آیا با حذف برنامه پاک می‌شوند؟**
همهٔ داده‌ها در `C:\ProgramData\CertificateAutomation` هستند. هنگام حذف برنامه، پایگاه داده
و سوابق **عمداً پاک نمی‌شوند** تا اطلاعاتتان از بین نرود.

**به‌روزرسانی به نسخهٔ جدید چطور است؟**
کافی است نسخهٔ جدید Setup را اجرا کنید؛ روی نسخهٔ قبلی نصب می‌شود و داده‌ها حفظ می‌مانند.

**می‌خواهم نصب حتی ساده‌تر باشد و کاربر LibreOffice را جدا نصب نکند. ممکن است؟**
بله، در فاز ۸ می‌توان نصاب LibreOffice را هم داخل همان Setup گنجاند تا کاربر فقط یک فایل
اجرا کند. این کار حجم Setup را زیاد می‌کند ولی نصب را کاملاً یک‌مرحله‌ای می‌کند.

---

## خلاصهٔ یک‌نگاهی

```
سیستم توسعه (یک بار، با اینترنت):
   نصب .NET 8 SDK + Inno Setup
   → dotnet publish (ساخت exe خوداتکا)
   → Compile در Inno Setup (ساخت Setup.exe)
   → فایل dist\CertificateAutomation-Setup-1.0.0.exe آماده است

سیستم مقصد (هر تعداد، بدون اینترنت):
   → اجرای Setup.exe
   → چند بار «بعدی»
   → (در صورت نیاز به PDF) نصب آفلاین LibreOffice
   → برنامه آمادهٔ استفاده است
```
