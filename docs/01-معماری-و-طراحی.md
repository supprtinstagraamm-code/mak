## ۳. نکته مهم: Interop در برابر OpenXML

درخواست اولیه «Microsoft Office Interop» بود. پیشنهاد من تغییر آن است، به این دلایل:

**مشکلات Interop:**
- نیاز به نصب بودن Microsoft Word روی هر سیستم مقصد (لایسنس + هزینه).
- روی سرور یا Session بدون UI ناپایدار است.
- در صورت کرش، پروسه `WINWORD.EXE` در حافظه باقی می‌ماند و به‌مرور سیستم را کند می‌کند.
- کند است (هر سند چند ثانیه).
- در نسخه خوداتکا (Self-contained) قابل اتکا نیست.

**راه‌حل پیشنهادی — معماری دو بخشی:**

1. **پر کردن Placeholder با OpenXML** — سریع، بدون نیاز به Word، کاملاً پایدار. خروجی: یک `.docx` تکمیل‌شده.
2. **تبدیل/چاپ/پیش‌نمایش با `IDocumentRenderer`** که در زمان اجرا بهترین گزینه موجود را انتخاب می‌کند:

| اولویت | پیاده‌سازی | شرط | قابلیت |
|---|---|---|---|
| ۱ | `WordInteropRenderer` | Word نصب باشد | PDF + چاپ مستقیم + پیش‌نمایش |
| ۲ | `LibreOfficeRenderer` | LibreOffice نصب باشد | PDF + چاپ (خط فرمان `soffice`) |
| ۳ | `ShellPrintRenderer` | همیشه | باز کردن سند با برنامه پیش‌فرض ویندوز |

پیش‌نمایش داخل برنامه از روی PDF تولیدشده و با WebView2 نمایش داده می‌شود؛ اگر هیچ Renderer‌ای موجود نبود، پیش‌نمایش «متنی» (نمایش مقادیر جایگزین‌شده) نشان داده می‌شود تا برنامه هرگز قفل نشود.

> اگر ترجیح می‌دهید دقیقاً طبق درخواست اولیه فقط Interop استفاده شود، همین کار انجام می‌شود؛ فقط لازم است نصب Word روی همه سیستم‌ها تضمین شود.

## ۶. موتور جایگزینی Placeholder

**چالش فنی:** Word یک عبارت مثل `{{کد_ملی}}` را اغلب بین چند `<w:t>` تقسیم می‌کند (به‌خاطر غلط‌گیر املایی یا تغییر قالب‌بندی). جایگزینی ساده متن، شکست می‌خورد.

**راه‌حل:** الگوریتم *Run Merge* — در هر پاراگراف، متن تمام Runها به‌هم چسبانده می‌شود، جایگزینی روی رشته کامل انجام می‌شود، سپس متن نهایی در اولین Run نوشته و بقیه خالی می‌شوند (قالب‌بندی اولین Run حفظ می‌شود).

پوشش: بدنه سند + Header + Footer + جدول‌ها + TextBoxها.

```
منابع مقدار برای هر Placeholder (به ترتیب اولویت):
1. مقادیر سیستمی   → شماره_نامه · تاریخ · ساعت · نام_شرکت
2. ستون‌های اصلی Employee
3. ExtraDataJson (ستون‌های جدید Excel)
4. ورودی دستی کاربر (فیلدهایی که در هیچ منبعی نبودند)
5. رشته خالی + هشدار در پیش‌نمایش
```

اسکنر Placeholder با الگوی `\{\{\s*([^\}]+?)\s*\}\}` قالب‌ها را می‌خواند و فهرست فیلدهای هر قالب را در `TemplatePlaceholders` ذخیره می‌کند؛ بنابراین افزودن قالب جدید **بدون تغییر کد** انجام می‌شود.

## ۷. تولید شماره نامه (بحرانی‌ترین بخش)

قواعد: بدون تکرار · ادامه‌دار پس از بستن برنامه · شروع مجدد در سال جدید شمسی · تغییر فقط توسط مدیر.

```
BEGIN IMMEDIATE TRANSACTION;
  INSERT OR IGNORE INTO NumberSequences(JalaliYear, LastSerial, UpdatedAt) VALUES (@y, 0, @now);
  UPDATE NumberSequences SET LastSerial = LastSerial + 1, UpdatedAt = @now WHERE JalaliYear = @y;
  SELECT LastSerial FROM NumberSequences WHERE JalaliYear = @y;
  INSERT INTO Letters (...) VALUES (...);
COMMIT;
```

- شماره **فقط هم‌زمان با ثبت رکورد نامه** و در یک تراکنش صادر می‌شود ← امکان «سوراخ» یا «شماره رزروشده بلااستفاده» وجود ندارد.
- `UNIQUE(JalaliYear, Serial)` و `UNIQUE(LetterNumber)` تضمین دوم در سطح دیتابیس.
- `BEGIN IMMEDIATE` + WAL ← ایمن حتی اگر فایل دیتابیس روی درایو شبکه و چند کاربر هم‌زمان باشند.
- قالب شماره از Settings: `{year}/{serial:00000}` — قابل تغییر به `{year}-{serial:0000}` یا افزودن پیشوند واحد.
- سال شمسی از `PersianCalendar.GetYear(DateTime.Now)`؛ در اولین صدور سال جدید، ردیف جدید خودکار ساخته می‌شود (بدون نیاز به اقدام کاربر).
- پنل مدیر: امکان تنظیم دستی `LastSerial` — با ثبت اجباری در `AuditLog`.

## ۹. امنیت

- تمام داده‌ها محلی؛ **هیچ درخواست شبکه‌ای در کد وجود ندارد** — قابل بررسی با Firewall.
- رمز مدیر با PBKDF2-SHA256، ۱۰۰٬۰۰۰ تکرار و Salt تصادفی ۱۶ بایتی ذخیره می‌شود (نه رمز خام، نه MD5).
- رمز پیش‌فرض `admin` / `admin123` با **اجبار به تغییر در اولین ورود**.
- بخش‌های محافظت‌شده: تنظیمات · حذف سابقه · تغییر شماره · بازیابی نسخه پشتیبان.
- قفل خودکار پنل مدیر پس از ۱۵ دقیقه بی‌فعالیتی.
- حذف نامه به‌صورت Soft Delete (`IsDeleted=1`) ← سابقه ممیزی از بین نمی‌رود.
- هر عملیات حساس در `AuditLog` ثبت می‌شود.

| امضای دیجیتال | `IDocumentSigner` در لایه Rendering |
| گزارش‌ها | `IReportProvider` + کوئری روی `Letters` |
| چند کاربره | جدول `AppUsers` و `AuditLog` از حالا موجود است |
| انتقال به SQL Server | تعویض `IConnectionFactory` — بدون تغییر UI |
