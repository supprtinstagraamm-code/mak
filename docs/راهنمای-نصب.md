<a name="روش-۱"></a>
## روش ۱: نصب با فایل Setup (ساده‌ترین)

اگر فایل `CertificateAutomation-Setup-1.0.0.exe` را دارید:

۱. روی فایل دوبار کلیک کنید.
۲. اگر ویندوز هشدار امنیتی داد، روی «More info» و سپس «Run anyway» بزنید
   (این هشدار برای همهٔ برنامه‌های بدون امضای دیجیتال طبیعی است).
۳. مسیر نصب را بپذیرید و «Next» بزنید.
۴. تیک «ایجاد میان‌بر روی میز کار» را بزنید و «Next».
۵. «Install» را بزنید و منتظر بمانید.
۶. «Finish» — برنامه اجرا می‌شود.

**تمام.** نیازی به اینترنت، .NET یا هیچ نرم‌افزار دیگری نیست. برنامه در اولین اجرا خودش
پایگاه داده، پوشه‌ها و کاربر مدیر را می‌سازد.

### اولین گواهی در ۵ کلیک

۱. بخش «کارکنان» → «بارگذاری از Excel» → فایل نمونه را انتخاب کنید:
   `C:\ProgramData\CertificateAutomation\SampleData\Employees.xlsx`
۲. بخش «قالب‌ها» → «همگام‌سازی قالب‌ها» (قالب‌های نمونه از قبل نصب شده‌اند).
۳. بخش «صدور نامه» → یک شخص انتخاب کنید → «مرحلهٔ بعد».
۴. یک قالب انتخاب کنید → «مرحلهٔ بعد».
۵. «صدور و ثبت نامه» را بزنید. نامه ساخته، شماره‌گذاری، ثبت و باز می‌شود.

<a name="روش-۲"></a>
## روش ۲: ساخت فایل نصب (برای مسئول فنی)

این کارها را **یک بار** روی سیستمی با اینترنت انجام می‌دهید تا فایل `Setup.exe` بسازید،
سپس آن فایل را روی هر تعداد سیستم آفلاین نصب می‌کنید.

### پیش‌نیازها (فقط روی سیستم توسعه)

۱. **.NET 8 SDK** → از `https://dotnet.microsoft.com/download/dotnet/8.0`
   (بخش «SDK x64»، نه Runtime).
۲. **Inno Setup 6** → از `https://jrsoftware.org/isdl.php` (رایگان).

### گام ۱: ساخت فایل اجرایی خوداتکا

در PowerShell، به پوشهٔ ریشهٔ پروژه بروید و اسکریپت آماده را اجرا کنید:
```powershell
cd مسیر\پروژه\CertificateAutomation
.\build.ps1
```

این اسکریپت خودش همه‌چیز را انجام می‌دهد: بررسی .NET، پاک‌سازی، بازیابی بسته‌ها و ساخت.
برای سیستم ۳۲ بیتی:
```powershell
.\build.ps1 -Arch win-x86
```

پس از اتمام، پوشهٔ `publish` ساخته می‌شود که داخلش `CertificateAutomation.exe` است.
«خوداتکا» یعنی .NET داخل این فایل بسته‌بندی شده، پس سیستم مقصد به .NET نیاز ندارد.
حجم حدود ۱۵۰MB طبیعی است.

> اگر نمی‌خواهید از اسکریپت استفاده کنید، فرمان دستی این است:
> ```powershell
> dotnet publish src\CertificateAutomation.UI\CertificateAutomation.UI.csproj `
>     -c Release -r win-x64 --self-contained true `
>     -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
> ```

### گام ۲: ساخت فایل نصب

**نسخهٔ استاندارد** (سبک‌تر، بدون LibreOffice):
۱. فایل `installer\setup.iss` را با Inno Setup باز کنید (راست‌کلیک → Open with Inno Setup).
۲. از منو: `Build → Compile` (یا F9).
۳. خروجی: `dist\CertificateAutomation-Setup-1.0.0.exe`

**نسخهٔ کامل** (همراه LibreOffice، برای نصب کاملاً یک‌مرحله‌ای):
اگر می‌خواهید کاربر برای خروجی PDF نیازی به نصب جداگانهٔ LibreOffice نداشته باشد:
۱. نصاب آفلاین LibreOffice (فرمت MSI) را از
   `https://www.libreoffice.org/download/download/` دانلود کنید.
۲. آن را در `installer\redist\LibreOffice.msi` قرار دهید.
۳. فایل `installer\setup-with-libreoffice.iss` را در Inno Setup باز و Compile کنید.
۴. خروجی: `dist\CertificateAutomation-Full-Setup-1.0.0.exe` (حجم بالا، ~۴۵۰MB).
   در این نسخه، هنگام نصب یک گزینهٔ «نصب LibreOffice» ظاهر می‌شود که خودکار آن را نصب می‌کند.

### گام ۳: انتقال به سیستم‌های آفلاین

فقط فایل `Setup.exe` ساخته‌شده را با فلش یا شبکهٔ داخلی به سیستم‌های مقصد ببرید و
طبق [روش ۱](#روش-۱) نصب کنید.

<a name="روش-۳"></a>
## روش ۳: اجرا بدون نصب (Portable)

اگر اصلاً نمی‌خواهید نصب کنید:

۱. روی سیستم توسعه، `build.ps1` را اجرا کنید (طبق روش ۲، گام ۱).
۲. کل پوشهٔ `publish` را کپی کنید و روی سیستم مقصد بگذارید.
۳. فایل `CertificateAutomation.exe` داخل آن را مستقیم اجرا کنید.

نکته: در این حالت هم برنامه داده‌هایش را در `C:\ProgramData\CertificateAutomation`
ذخیره می‌کند و کاملاً کار می‌کند. فقط میان‌بر خودکار ساخته نمی‌شود.

<a name="pdf-و-چاپ"></a>
## خروجی PDF و چاپ روی سیستم‌های آفلاین

برنامه برای «پر کردن قالب و ساخت سند Word» به هیچ نرم‌افزار جانبی نیاز ندارد.
اما برای «خروجی PDF» و «چاپ باکیفیت»، به یکی از این دو نیاز دارد:

**گزینهٔ الف — Microsoft Word:** اگر روی سیستم مقصد Word نصب و فعال‌سازی‌شده باشد،
برنامه خودکار از آن استفاده می‌کند (بهترین کیفیت). نیازی به تنظیم نیست.

**گزینهٔ ب — LibreOffice (رایگان، توصیه‌شده برای سیستم‌های بدون Word):**
چون روی خیلی از سیستم‌های ایران Word فعال‌سازی‌شده نیست، LibreOffice گزینهٔ مطمئن است.

سه راه برای نصب LibreOffice:
1. **همراه با برنامه:** اگر از «نسخهٔ کامل» فایل نصب استفاده کنید (روش ۲)، خودکار نصب می‌شود.
2. **جداگانه و آفلاین:** نصاب آفلاین LibreOffice را از سایتش دانلود، با فلش به سیستم مقصد
   ببرید و نصب کنید. برنامه خودکار تشخیصش می‌دهد.
3. **بدون نصب هیچ‌کدام:** برنامه باز هم کار می‌کند و سند Word می‌سازد؛ فقط دکمهٔ PDF
   پیام می‌دهد که برای PDF باید Word یا LibreOffice نصب شود.

> برنامه در زمان اجرا خودش تشخیص می‌دهد چه چیزی نصب است و بهترین گزینه را انتخاب می‌کند:
> ابتدا Word، سپس LibreOffice، و در نهایت چاپ پیش‌فرض خود ویندوز. **پس هرگز به‌خاطر
> نبودن Word قفل نمی‌شود.**

<a name="رفع-اشکال"></a>
## رفع اشکالات رایج

**ویندوز هنگام اجرای Setup هشدار امنیتی می‌دهد.**
طبیعی است (برنامه امضای دیجیتال ندارد). روی «More info» → «Run anyway» بزنید.

**برنامه اجرا نمی‌شود / بلافاصله بسته می‌شود.**
فایل لاگ را بررسی کنید: `C:\ProgramData\CertificateAutomation\logs`
معمولاً علت، نبود دسترسی نوشتن است؛ برنامه را یک بار «Run as administrator» اجرا کنید.

**دکمهٔ خروجی PDF کار نمی‌کند.**
یعنی نه Word و نه LibreOffice نصب نیست. طبق [بخش PDF](#pdf-و-چاپ) یکی را نصب کنید.

**فایل Excel بارگذاری نمی‌شود.**
مطمئن شوید فایل در برنامهٔ Excel باز نباشد (قفل فایل). آن را ببندید و دوباره تلاش کنید.

**رمز مدیر را فراموش کرده‌ام.**
رمز پیش‌فرض `admin` / `admin123` است. اگر تغییرش داده‌اید و فراموش کرده‌اید، با حذف فایل
پایگاه داده (`C:\ProgramData\CertificateAutomation\Data\certdb.sqlite`) برنامه از نو ساخته
می‌شود — اما **توجه: تمام سوابق پاک می‌شود**. پیش از این کار حتماً نسخهٔ پشتیبان بگیرید.

**می‌خواهم داده‌ها روی درایو دیگری ذخیره شوند.**
پس از نصب، از بخش «تنظیمات» (با ورود مدیر) مسیرها را تغییر دهید.

## خلاصهٔ یک‌نگاهی

```
کاربر نهایی:
   Setup.exe → چند بار Next → آماده است

مسئول فنی (یک بار):
   نصب .NET 8 SDK + Inno Setup
   → build.ps1  (ساخت publish)
   → Compile در Inno Setup  (ساخت Setup.exe)
   → توزیع Setup.exe روی سیستم‌های آفلاین

برای PDF روی سیستم بدون Word:
   نصب LibreOffice (جداگانه یا همراه نسخهٔ کامل)
```
