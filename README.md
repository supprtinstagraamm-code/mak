# سامانه اتوماسیون صدور گواهی

نرم‌افزار ویندوزی آفلاین برای صدور خودکار گواهی‌ها و نامه‌های اداری.
**وضعیت: ✅ نسخهٔ نهایی ۱.۰.۰ — کامل و آمادهٔ استفاده**

---

## اجرای پروژه در ۳ دقیقه

```powershell
# ۱) بازیابی بسته‌ها و کامپایل
cd CertificateAutomation
dotnet restore
dotnet build -c Debug

# ۲) اجرا
dotnet run --project src\CertificateAutomation.UI
```

یا فایل `CertificateAutomation.sln` را در Visual Studio 2022 باز کنید، پروژه `CertificateAutomation.UI` را
به‌عنوان Startup Project انتخاب کنید و F5 بزنید.

**پیش‌نیاز:** .NET 8 SDK — از `https://dotnet.microsoft.com/download/dotnet/8.0` (بسته «SDK x64»).

در اولین اجرا، برنامه به‌صورت خودکار پایگاه داده، پوشه‌ها و کاربر مدیر پیش‌فرض را می‌سازد.
هیچ کار دستی لازم نیست.

---

## ساخت نسخه نهایی (EXE خوداتکا + فایل نصب)

```powershell
# خروجی تک‌فایل، بدون نیاز به نصب .NET روی سیستم مقصد
dotnet publish src\CertificateAutomation.UI -c Release -r win-x64 --self-contained true ^
    -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true ^
    -o publish
```

سپس فایل `installer\setup.iss` را با **Inno Setup 6** (رایگان، از `https://jrsoftware.org/isdl.php`)
باز کرده و `Build ← Compile` بزنید. خروجی: `dist\CertificateAutomation-Setup-1.0.0.exe`

> اگر سیستم‌های مقصد ۳۲ بیتی هستند، `win-x64` را به `win-x86` تغییر دهید.

## ساختار پروژه

```
CertificateAutomation.sln
├─ src/CertificateAutomation.Domain          موجودیت‌ها و مفاهیم پایه (بدون وابستگی خارجی)
├─ src/CertificateAutomation.Application     اینترفیس سرویس‌ها و DTOها (قرارداد بین لایه‌ها)
├─ src/CertificateAutomation.Infrastructure  SQLite، امنیت، لاگ، Excel، Word، چاپ
├─ src/CertificateAutomation.UI              WPF + MVVM (فارسی و راست‌چین)
├─ installer/setup.iss                       اسکریپت ساخت فایل نصب
├─ SampleData/                               فایل Excel، قالب‌ها و لوگوی نمونه
└─ docs/                                     راهنمای نصب و استفاده
```

قاعده وابستگی: `UI → Application → Domain` و `Infrastructure → Application → Domain`.
لایه UI هرگز مستقیماً به Infrastructure ارجاع نمی‌دهد؛ همه‌چیز از طریق تزریق وابستگی در
`App.xaml.cs` وصل می‌شود. نتیجه: تعویض SQLite یا تعویض موتور Word، بدون تغییر رابط کاربری ممکن است.

## نکات فنی مهم

**۱. مسیر داده‌ها.** همه داده‌ها زیر `C:\ProgramData\CertificateAutomation` ذخیره می‌شوند
(پایگاه داده، لاگ، قالب‌ها، خروجی‌ها، نسخه پشتیبان). این پوشه برای کاربر عادی قابل نوشتن است،
بنابراین برنامه نیازی به اجرا با دسترسی Administrator ندارد.

**۲. مسیر پایگاه داده.** چون خودِ مسیر پایگاه داده یک تنظیم است، در فایل کوچک
`bootstrap.json` نگهداری می‌شود و بقیه تنظیمات داخل جدول `Settings` قرار دارند.

**۳. تاریخ و ارقام.** تاریخ‌های شمسی به‌صورت متن `yyyy/MM/dd` با ارقام انگلیسی ذخیره می‌شوند
تا مرتب‌سازی و مقایسه بازه‌ای درست کار کند. تبدیل به ارقام فارسی فقط در لایه نمایش
(`PersianDigitsConverter`) انجام می‌شود و از تنظیمات قابل خاموش کردن است.
زمان‌های سیستمی با قالب ISO و فرهنگ Invariant ذخیره می‌شوند تا فرهنگ فارسی برنامه در
تبدیل‌ها دخالت نکند.

**۴. رمز پیش‌فرض مدیر.** `admin` / `admin123` — برنامه در فاز ۷ تغییر آن را در اولین ورود اجباری می‌کند.
رمز با PBKDF2-SHA256 و ۱۰۰٬۰۰۰ تکرار ذخیره می‌شود؛ رمز خام هرگز در پایگاه داده نیست.

**۵. فونت فارسی.** فایل `Vazirmatn-Regular.ttf` را در
`src/CertificateAutomation.UI/Assets/Fonts/` قرار دهید تا داخل برنامه Embed شود
(لایسنس OFL، توزیع تجاری آزاد). در نبود آن، برنامه به Segoe UI و Tahoma برمی‌گردد و بدون خطا اجرا می‌شود.

**۶. حالت آفلاین.** هیچ فراخوانی شبکه‌ای در کد وجود ندارد. تنها ارتباط اینترنتی، بازیابی
بسته‌های NuGet هنگام کامپایل روی سیستم توسعه‌دهنده است؛ سیستم کاربر نهایی نیازی به اینترنت ندارد.
